# ALIFLY — интерактивное изучение арабского языка

> Рабочее название проекта. Финальный бренд ещё предстоит выбрать.

ALIFLY — мобильная образовательная платформа для русскоязычных начинающих. Основной курс посвящён современному литературному арабскому языку (фусха).

## Идея продукта

- Первые 5 уроков доступны бесплатно.
- После бесплатного блока ученик может приобрести полный доступ один раз.
- Платный доступ планируется активировать уникальным кодом, привязанным к аккаунту.
- Короткие объяснения, упражнения, тесты и постепенное открытие учебных этапов.
- Интерфейс в игровом стиле, с собственным визуальным языком.

## Текущая основа

- React 18 + TypeScript + Vite.
- Адаптивный интерфейс для мобильных экранов.
- 5 первых уроков по буквам арабского алфавита.
- Контрольный тест после бесплатного блока.
- Повторение ошибок, баллы опыта и серия занятий.
- Локальное сохранение прогресса в браузере.
- PWA-манифест и service worker для установки и базовой офлайн-работы.

## Локальный запуск

Требуется Node.js 22 или совместимая актуальная LTS-версия.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

Vite настроен с базовым путём `/alifly/`. Перед включением публикации нужно настроить GitHub Pages через GitHub Actions и проверить URL:

`https://iamaldamov.github.io/alifly/`

На текущем этапе CI проверяет сборку; автоматическая публикация сайта ещё не считается настроенной.

## Что пока НЕ реализовано

- Регистрация и вход в аккаунт.
- Синхронизация прогресса между устройствами.
- Серверная защита платных уроков.
- Проверка и одноразовая активация кодов.
- Подтверждение платежей и автоматическая выдача кодов.
- Реальный аудиокаталог произношения.
- Рабочий ИИ-репетитор (интерфейс подключения подготовлен отдельно, но сам сервис не развёрнут).

До подключения серверной части локальный прогресс и любые проверки на стороне браузера нельзя считать защитой платного доступа.

## Важные правила качества

1. Не публиковать секретные ключи в репозитории и браузерном коде.
2. Проверять арабский текст, огласовки, транскрипцию и перевод по надёжным источникам.
3. Не смешивать фусха, диалекты и правила чтения Корана без отдельного объяснения.
4. Сначала проверять изменения в отдельной ветке и GitHub Actions, затем переносить их в `main`.
5. Не заявлять о готовой оплате, аккаунтах или серверной безопасности, пока они фактически не реализованы.
