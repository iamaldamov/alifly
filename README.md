# ALIFLY

Interactive Arabic learning platform.

ALIFLY — бесплатный проект для русскоязычных учеников, которые хотят изучать арабский язык с нуля.

## Обратная связь

Помогите нам сделать ALIFLY лучше: сообщите об ошибке или предложите улучшение.

**[Оставить отзыв или предложение](https://github.com/iamaldamov/alifly/issues/new/choose)**

Перед отправкой выберите подходящий вариант:
- **Сообщить об ошибке** — если что-то работает неправильно.
- **Предложить улучшение** — если у вас есть идея для развития проекта.

Все обращения принимаются на русском языке. Пожалуйста, не публикуйте личные данные.

Подробнее: [как помочь проекту](CONTRIBUTING.md).
