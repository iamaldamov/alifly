# Система интервального повторения ALIFLY

## Цель

Помогать переносить знания в долговременную память через повторение в нужный момент, а не показывать все ошибки бесконечно.

## Текущая логика прототипа

Для каждого вопроса создаётся отдельная карточка повторения:
- идентификатор урока и вопроса;
- дата следующего повторения;
- текущий интервал в днях;
- количество успешных повторений подряд;
- коэффициент лёгкости.

Расписание:
- Неверный ответ: повторить через 10 минут; серия успешных повторений сбрасывается.
- Первый правильный ответ: повторить через 1 день.
- Второй успешный интервал: через 3 дня.
- Далее: предыдущий интервал умножается на коэффициент лёгкости (начально 2,5), результат округляется до целого дня.
- Коэффициент растёт на 0,1 после правильного ответа и снижается на 0,2 после ошибки; границы — 1,3 и 3,0.

В тренировку попадают только карточки, срок которых уже наступил.

Правильные ответы в режиме повторения не дают XP, чтобы нельзя было бесконечно фармить баллы на уже знакомых вопросах.

## Технические ограничения

- Сейчас расписание хранится в localStorage этого браузера.
- Очистка данных браузера может удалить прогресс.
- Между устройствами синхронизации нет.
- Время устройства может быть изменено пользователем.
- Это учебная реализация интервального повторения, вдохновлённая принципами SM-2, а не научно валидированная персональная модель памяти.

## Следующее развитие

1. Хранить расписание на сервере после подключения аккаунтов.
2. Добавить карточки не только для тестовых вопросов, но и для букв, чтения слогов, слов и грамматических конструкций.
3. Добавить самооценку ответа («трудно», «нормально», «легко») после показа решения.
4. Учитывать скорость ответа и повторяющиеся ошибки, не наказывать за пропуски.
5. Поддерживать ежедневную короткую сессию на 5–10 минут.
6. Добавить смешанные задания: распознавание буквы, выбор звучания, чтение с огласовкой и различение похожих букв.
