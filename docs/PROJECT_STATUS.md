# ALIFLY — статус разработки

Обновлено: 5 ноября 2026 года.

## Сейчас есть

- Репозиторий: https://github.com/iamaldamov/alifly
- Рабочая основа: ветка `setup/react-vite-foundation`.
- Продолжающая ветка этой задачи: `feature/pwa-and-foundation-docs`.
- React + TypeScript + Vite.
- Главная страница и карта из 6 учебных этапов.
- Пять бесплатных уроков с интерактивными вопросами.
- Экзамен из 10 вопросов, проходной результат — 8 правильных ответов.
- Повторение ошибок, XP и серия занятий.
- Локальное хранение состояния в браузере.
- Последняя проверенная сборка исходной ветки: GitHub Actions завершился успешно 4 ноября 2026 года.

## Добавлено в этом этапе

- Манифест PWA.
- SVG-иконка приложения.
- Service worker с сетевым обновлением главной страницы и кэшированием статических ресурсов.
- Регистрация service worker только в production.
- Улучшенные метаданные для мобильных устройств.
- Документация проекта и границ текущей реализации.
- CI запускается на ветках `setup/**` и `feature/**`.

## Что важно исправить до публичного запуска

1. Переосмыслить переход после пятого бесплатного урока: сейчас логика открытия следующего этапа связана с экзаменом, а не с покупкой полного доступа. Не считать эту проверку платной защитой.
2. Подключить Supabase Auth и хранение прогресса на сервере.
3. Сделать серверную проверку одноразовых кодов с атомарной активацией.
4. Связать выдачу кодов с подтверждённой оплатой.
5. Подготовить и проверить учебный материал с преподавателем арабского языка.
6. Подключить реальные аудиообразцы произношения.
7. Провести мобильное тестирование на iPhone и Android.
8. Настроить и проверить GitHub Pages deployment.
9. Утвердить окончательное название и проверить домен/товарный знак.

## Ограничения текущего прототипа

Прогресс сейчас хранится в localStorage и не синхронизируется между устройствами. Клиентский код можно изменить, поэтому нельзя использовать локальное состояние как подтверждение покупки или право на платный доступ.

ИИ-репетитор не развёрнут. Cloudflare Worker и Gemini требуют отдельной конфигурации и проверки условий использования.

## Следующий рекомендуемый этап

Проверить PWA на собранной версии, затем исправить учебно-коммерческий сценарий «5 бесплатных уроков → экзамен → предложение полного доступа», после чего подключать Supabase.
