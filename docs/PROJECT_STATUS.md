# ALIFLY — статус разработки

Обновлено: 11 ноября 2026 года.

## Рабочая версия

- Репозиторий: https://github.com/iamaldamov/alifly
- Сайт: https://iamaldamov.github.io/alifly/
- Стек: React + TypeScript + Vite, Supabase Auth и хранение прогресса, GitHub Pages.

## Что реализовано

- 28 букв арабского алфавита разбиты на девять коротких уроков по 2–4 буквы.
- Каждый урок разделён на две фазы: изучение карточек и проверка без списка ответов.
- Названия букв нужно вводить самостоятельно; задания на узнавание перемежаются с активным воспроизведением.
- Практика огласовок и отдельный тренажёр чтения принимают ввод ответа, а не только выбор из готовых вариантов.
- Итоговый экзамен проверяет самостоятельное воспроизведение названий букв.
- Интервальное повторение: 10 минут после ошибки, затем 1, 3, 7, 14 и 30 дней после последовательных правильных ответов.
- Есть отдельная тренировка просроченных карточек и раздел «Слабые слова».
- Прогресс хранится локально и синхронизируется с аккаунтом Supabase.
- PWA-манифест, иконки и service worker подключены.
- После последних изменений GitHub Actions успешно выполнил сборку и публикацию на GitHub Pages.

## Что пока не реализовано

- Полноценный раздел «Знакомство» с контекстными диалогами и пятью уроками.
- Выбор дорожки MSA / египетский / левантийский диалект.
- Показ позиционных форм букв с анимацией соединения.
- Shadowing с аудио носителей, двумя голосами и замедлением.
- Автоматическая оценка произношения и проверка рукописного арабского.
- Полная мобильная ручная проверка на реальном iPhone и Android.
- Преподавательская проверка полного учебного плана и аудиоматериалов.

## Методические ограничения

Активное воспроизведение и распределённая практика применены как основа тренировки памяти. Текущая система интервальных повторений — прозрачная модель Leitner, а не индивидуально научно откалиброванный прогноз забывания. Ввод русского звучания помогает проверять чтение базовых сочетаний, но не заменяет постановку арабского произношения с преподавателем или проверенные аудиопримеры.

Арабские карточки, транскрипции и заметки исходного курса не переписываются без надёжного источника и лингвистической проверки.
