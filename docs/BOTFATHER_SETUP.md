# Создание ALIFLY-бота через BotFather

## 1. Создай бота
1. Открой Telegram и найди официальный аккаунт [@BotFather](https://t.me/BotFather) с синей отметкой.
2. Нажми Start и отправь команду `/newbot`.
3. Имя бота: `ALIFLY — арабский с нуля`.
4. Придумай username, который заканчивается на `bot`, например `AliflyArabicBot` (если свободен).
5. BotFather покажет API token. Это пароль от управления ботом: не отправляй его в чат, не публикуй в GitHub и не показывай на скриншотах. Сохрани его в надёжном менеджере паролей; позже добавим его в Cloudflare как Worker secret.

## 2. Заполни описание
В BotFather выбери своего бота через `/mybots` → Bot Settings → Edit Description и добавь:

ALIFLY — интерактивная платформа для изучения арабского языка с нуля. Изучай алфавит, учись читать, осваивай слова и грамматику, проходи уроки и отслеживай свой прогресс прямо в Telegram.

Через Edit About добавь короткий текст:

Арабский язык с нуля. Уроки, практика и твой прогресс — в одном месте.

## 3. Добавь команды
Через `/setcommands` выбери бота и отправь:

```text
start - Открыть ALIFLY
progress - Мой прогресс
help - Помощь
```

## 4. Mini App подключим после публикации
Когда HTTPS-версия Mini App будет готова, настроим её домен и кнопку меню через BotFather. Пока не указывай случайный URL и не создавай неработающую кнопку.

## Что сообщить разработчику
После создания пришли только публичный username бота вида `@AliflyArabicBot`. Сам API token не присылай — он должен остаться секретом и будет добавлен непосредственно в Cloudflare Worker secrets.
