# ALIFLY — эталонный микроурок чтения № 1

Статус: учебный прототип для лингвистической вычитки; не добавлен в приложение  
Тема: первое настоящее слово из уже изученных букв и кратких огласовок  
Основной пример: كَتَبَ  
Перенос навыка: دَرَسَ

## 1. Зачем нужен этот урок

Текущий курс уже знакомит ученика с буквами и тремя краткими огласовками, но пока не показывает полноценный переход к чтению настоящих слов. Этот урок проверяет, может ли ученик соединить знакомые элементы в одно читаемое слово.

Это не новый этап грамматики и не полноценный урок глагольных форм. Грамматическое значение слова даётся только настолько, насколько нужно для понимания примера.

## 2. Цель урока

После занятия ученик сможет:
- прочитать слово كَتَبَ справа налево;
- увидеть в нём три знакомые буквы и три фатхи;
- понять, почему буквы в слове имеют соединённые формы;
- прочитать другое короткое слово с тем же знакомым принципом без готовой разбивки.

## 3. Что ученик уже должен знать

Обязательные предварительные знания:
- буквы ك، ت، ب، د، ر، س;
- краткую огласовку фатха;
- чтение арабской строки справа налево.

Новые знаки в уроке не вводятся. Сукун, танвин, шадда и долгие гласные не используются.

## 4. Основное слово

### كَتَبَ

- Учебная латинская транслитерация: *kataba*.
- Приблизительная русская подсказка для чтения: «ка-та-ба».
- Значение в данном примере: «он написал».
- Часть речи: глагол, форма прошедшего времени, 3-е лицо мужского рода, единственное число.

Важно для объяснения: не переводить *kataba* как абстрактный инфинитив «писать». В арабском это конкретная глагольная форма «он написал». Подробную грамматику прошедшего времени ученик изучит позже.

### Разбор по знакам

Читать нужно справа налево:

- كَ — kāf с фатхой, учебная подсказка «ка»;
- تَ — tāʾ с фатхой, учебная подсказка «та»;
- بَ — bāʾ с фатхой, учебная подсказка «ба».

Вместе: كَتَبَ — *kataba* — «он написал».

Русская подсказка передаёт только приблизительное соответствие и не является оценкой точности арабского произношения.

## 5. Как показать соединение

Порядок чтения слова справа налево: ك → ت → ب.

- ك — первая буква слова; в связной записи использует начальную форму كـ.
- ت — средняя буква; использует срединную форму ـتـ.
- ب — последняя буква; использует конечную форму ـب.

Отдельные буквы: ك + ت + ب  
Соединённое написание без огласовок: كتب  
С огласовками: كَتَبَ

В интерфейсе нельзя размещать буквы слева направо так, будто арабское слово читается в этом направлении. Подписи «первая / средняя / последняя» должны быть привязаны к порядку чтения, а не к визуальному расположению элементов в русскоязычной сетке.

## 6. Последовательность урока

### Экран 1. Первое настоящее слово

Показать крупно كَتَبَ и перевод «он написал». Сказать, что все три буквы уже знакомы, а задача — прочитать их вместе.

### Экран 2. Найди знакомые элементы

Подсветить по очереди كَ, تَ, بَ. Для каждого элемента показать знакомую букву и фатху. Не показывать три подсказки одновременно во время самостоятельной проверки.

### Экран 3. Почему буквы изменили форму

Сопоставить отдельные формы ك، ت، ب с их соединёнными позиционными формами в слове. Объяснить только один факт: форма буквы зависит от того, соединяется ли она с соседними буквами.

Не требовать заучивания всех четырёх форм каждой буквы в этом одном уроке. Это отдельная учебная цель для следующего блока.

### Экран 4. Собери слово

Попросить поставить три знакомые буквы в правильном порядке. Направление чтения явно указать стрелкой справа налево. После ответа показать соединённую запись كَتَبَ.

### Экран 5. Прочитай без разбивки

Показать только كَتَبَ. Ученик вводит *kataba* или выбирает подходящий вариант чтения, если это первая практика самостоятельного чтения. В последующих уроках постепенно убрать варианты.

### Экран 6. Проверь значение

Спросить, что означает كَتَبَ:
- он написал;
- книга;
- ручка.

После ответа объяснить, что здесь показана глагольная форма «он написал», а не существительное «книга».

### Экран 7. Перенос на новый пример

Показать دَرَسَ без разложения на слоги:
- транслитерация для обратной связи: *darasa*;
- смысл: «он изучал / учился» в подходящем контексте;
- буквы د، ر، س и фатха уже знакомы.

Ученик должен применить тот же способ чтения, но не просто повторить предыдущую последовательность. Значение и контекст должны быть объяснены кратко. Если преподаватель предпочитает другой точный русский эквивалент, он должен быть зафиксирован в контентной карточке до публикации.

### Экран 8. Итоговое воспроизведение

Ученик без подсказки:
1. читает كَتَبَ;
2. указывает порядок букв;
3. выбирает значение;
4. читает دَرَسَ как новый пример.

## 7. Примеры заданий

| Навык | Стимул | Действие ученика |
|---|---|---|
| Распознавание | كَتَبَ | Найти три известные буквы |
| Звуко-буквенное соответствие | كَ / تَ / بَ | Прочитать каждый элемент |
| Направление | كَتَبَ | Указать, откуда начинается чтение |
| Позиционная форма | كـ / ـتـ / ـب | Соотнести форму с позицией |
| Сборка | ك + ت + ب | Собрать слово |
| Самостоятельное чтение | كَتَبَ | Ввести чтение без разбивки |
| Понимание | كَتَبَ | Выбрать «он написал» |
| Перенос | دَرَسَ | Прочитать незнакомую ранее последовательность |

## 8. Обратная связь

После ошибки не говорить только «неправильно». Уточнить, что именно нужно проверить:
- направление чтения;
- порядок букв;
- наличие фатхи;
- соединённую форму;
- значение глагола.

Не объявлять ошибку в русской транскрипции ошибкой арабского произношения. Без проверенной записи и оценки преподавателя приложение может проверить только выбранное или введённое текстовое соответствие.

## 9. Критерий успешного прохождения

Для прототипа предлагается:
- не менее 8 правильных ответов из 10 в итоговой проверке;
- обязательный правильный самостоятельный разбор и чтение كَتَبَ;
- обязательная попытка переноса на دَرَسَ.

Если ученик набрал общий проходной балл, но не смог прочитать новый пример, урок не должен показывать навык «чтение освоено». Следует предложить дополнительную практику и повторную проверку.

Порог 8/10 — продуктовый критерий ALIFLY, а не научно универсальная граница языкового мастерства.
