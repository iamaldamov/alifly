# ALIFLY 2.0 — отчёт об обновлении

Дата: 21 ноября 2026 года

## 1. Цель

Сделать Alifly более понятным и мотивирующим для регулярного изучения арабского языка, не ломая существующую учебную механику и не заявляя о функциях, которых пока нет.

## 2. Исходное состояние проекта

Репозиторий: https://github.com/iamaldamov/alifly

Публичная версия: https://iamaldamov.github.io/alifly/

Технологии: React 18, TypeScript, Vite, Firebase Authentication, Cloud Firestore, PWA и GitHub Pages.

В исходной версии уже были:
- 28 букв арабского алфавита, разбитых на девять коротких уроков;
- отдельные этапы изучения и проверки;
- итоговый экзамен из 10 заданий;
- тренажёр чтения и практика огласовок;
- интервальное повторение, слабые карточки и сохранение учебного прогресса;
- синхронизация основного прогресса через Firebase для вошедших пользователей.

## 3. Что добавлено в ALIFLY 2.0

### Недельный ритм обучения

Создан новый компонент `src/WeeklyRhythm.tsx` и встроен в главную страницу сразу после блока «Миссия дня».

Возможности:
- календарная неделя с понедельника по воскресенье;
- визуальное выделение текущего дня;
- отметка о завершённом занятии за сегодня;
- возможность отменить отметку;
- счётчик количества учебных дней за текущую неделю;
- сохранение отметок в браузере на этом устройстве;
- обработка ситуации, когда браузерное хранилище недоступно.

### Дизайн и адаптивность

В `src/styles.css` добавлены отдельные стили недельного трекера:
- светлая природная палитра, согласованная с визуальным языком Alifly;
- контрастная отметка текущего дня;
- состояния завершённого и незавершённого занятия;
- мобильная адаптация для узких экранов;
- видимые состояния кнопки и доступные подписи.

### Важная граница функциональности

Недельные отметки сохраняются локально в браузере. Они пока не синхронизируются между устройствами и не объединены с облачной историей Firebase. Интерфейс прямо сообщает пользователю о локальном хранении.

## 6. Проверки

Выполнено:
- проверено, что новый компонент и его импорт присутствуют в ветке PR;
- проверено, что компонент встроен в главную страницу;
- проверена структура восьми слайдов Figma и наличие редактируемых слоёв;
- проверено, что все элементы слайдов находятся в пределах холста после финальной корректировки.

Автоматическая сборка GitHub Actions запущена событием Pull Request. На момент составления отчёта проверка находилась в статусе `in_progress`; успешное завершение сборки не подтверждено.

## 7. Что ещё не сделано

Это обновление не включает:
- облачную синхронизацию недельных отметок;
- новые аудиозаписи носителей арабского языка;
- автоматическую оценку произношения;
- проверку рукописного арабского;
- профессиональную сертификацию учебного контента преподавателем;
- слияние PR в `main` и публикацию новой версии на GitHub Pages.

## 8. Рекомендуемые следующие шаги

1. Дождаться результата GitHub Actions и исправить возможные ошибки сборки.
2. Проверить недельный трекер на реальных устройствах iPhone и Android.
3. Получить обратную связь от первых учеников.
4. При подтверждённом спросе добавить синхронизацию недельных отметок через Firebase.
5. Организовать редакторскую проверку контента и лицензированные аудиозаписи.
6. После проверки принять PR и опубликовать обновление.

## 9. Итог

В рамках ALIFLY 2.0 подготовлена одна новая пользовательская функция — недельный ритм обучения, адаптивно встроенный в главную страницу. Также создана презентация из восьми редактируемых слайдов и этот технический отчёт.

Обновление находится в отдельном Pull Request и ещё не опубликовано в основной версии сайта.
