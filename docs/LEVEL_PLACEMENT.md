# ALIFLY — старт по уровню ученика

## Маршруты

| Уровень | Выбор ученика | Первый урок |
|---|---|---|
| 1 | Начинаю с нуля | Алфавит, урок 20 |
| 2 | Знаю буквы | Огласовки, урок 6 |
| 3 | Читаю простые слова | Чтение слов, урок 35 |
| 4 | Уже умею читать | Диалоги MSA, урок 30 |

Выбор уровня не отмечает предыдущие уроки или экзамены пройденными. Он только открывает соответствующую точку старта. Предыдущие этапы остаются доступными, а завершённый прогресс не сбрасывается.

Уровень хранится отдельно для гостевого режима и каждого Firebase UID в локальном хранилище, а после входа синхронизируется в документе прогресса users/{uid}/progress/current через поле starting_level.

## Входная диагностика

Диагностика адаптивная и останавливается при первой ошибке:

1. Узнавание буквы ب — при ошибке маршрут начинается с алфавита.
2. Чтение بَ — при ошибке маршрут начинается с огласовок.
3. Чтение كِتَاب — при ошибке маршрут начинается с огласовок и чтения слогов.
4. Понимание مَا اسْمُكَ؟ — при ошибке маршрут начинается с простых слов; при полном успехе — с диалогов MSA.

Результат является стартовой рекомендацией, а не сертификацией уровня. Его можно изменить в профиле. Уровни 3 и 4 открывают более поздние этапы, но не записывают предыдущие этапы как пройденные.

## Словарные карточки уровня 3

Первые карточки используют базовую лексику современного литературного арабского:

- كِتَاب — kitāb — книга.
- قَلَم — qalam — ручка / перо.
- بَاب — bāb — дверь.
- بَيْت — bayt — дом.

Проверка значений и чтения выполнена по словарным и учебным источникам:

- Cairo Arabic Language Academy, entry for الكِتابُ: https://www.arabicacademy.gov.eg/ar/%D9%85%D8%AD%D8%B1%D9%83-%D8%A7%D9%84%D8%A8%D8%AD%D8%AB/%D8%A7%D9%84%D9%83%D9%90%D8%AA%D8%A7%D8%A8%D9%8F?exact_search=true
- Cairo Arabic Language Academy, entry for القَلَمُ: https://www.arabicacademy.gov.eg/ar/%D9%85%D8%AD%D8%B1%D9%83-%D8%A7%D9%84%D8%A8%D8%AD%D8%AB/%D9%85%D8%B9%D8%AC%D9%85/dic-19/%D9%82%D9%84%D9%85
- Wazn Arabic, بَاب: https://waznarabic.com/word/bab/
- World Class Education, Arabic 101: https://www.mywce.org/arabic101/

Это начальный набор слов, а не полный словарь. Новые слова, примеры и грамматические объяснения следует добавлять только после сверки с надёжным источником; религиозные цитаты не добавляются автоматически.

## Ограничения текущей версии

- Уровень 4 пока начинает обучение с уже существующих диалогов на MSA. Полный модуль грамматики и расширенный словарь ещё предстоит разработать.
- В этой итерации не добавляются аудиофайлы. Системный синтез речи браузера нельзя называть записью носителя.
- Диагностика проверяет узнавание букв, чтение одной огласовки, простого слова и понимание знакомой фразы. Она не заменяет преподавательскую оценку чтения и произношения.
- Новые карточки нуждаются в финальной вычитке преподавателем арабского языка перед расширением курса.
